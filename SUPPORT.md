# Support

> Fiscal convention: monetary values in the Drenyra ecosystem are BigInt cents; no float is ever used for money; version numbers are JSON integers, never floats.

## Community Support

- **Issues**: use GitHub Issues on the relevant product repository for bug reports and feature requests. Issues are triaged by maintainers:
  - [drenyra-command-center](https://github.com/arkelythex/drenyra-command-center/issues)
  - [drenyra-ai](https://github.com/arkelythex/drenyra-ai/issues)
  - [drenyra-shell](https://github.com/arkelythex/drenyra-shell/issues)
  - [drenyra-engram](https://github.com/arkelythex/drenyra-engram/issues)
  - [drenyra-skills](https://github.com/arkelythex/drenyra-skills/issues)
  - [drenyra-guardian-angel](https://github.com/arkelythex/drenyra-guardian-angel/issues)
- **Discussions**: open a discussion or an issue for questions and general inquiries — public answers help everyone.

## Product Support

| Product | Channel |
| --- | --- |
| Drenyra ecosystem (all six core repositories) | [Issues across the organization](https://github.com/search?q=org%3Aarkelythex+is%3Aissue&type=issues) |
| Security | [SECURITY.md](SECURITY.md) — private vulnerability reporting |

## Response Times

| Severity | Response time |
| --- | --- |
| Critical (security, data loss) | Within 24h |
| High (blocking bug) | Within 48h |
| Normal | Within 5 business days |
| Low | Within 10 business days |

## Non-goals

- No private chat for bug reports — issues keep the audit trail; security vulnerabilities must use the private reporting path in [SECURITY.md](SECURITY.md).
- This organization does not provide tax/legal advice through support channels.
