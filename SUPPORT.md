# Support

> Fiscal convention: monetary values in the Drenyra ecosystem are BigInt cents; no float is ever used for money; schema and contract revision fields are JSON integers, never floats.

## Community Support

- **Issues**: use GitHub Issues on the **relevant product repository** (drenyra-console, drenyra-ai, drenyra-shell, drenyra-engram, drenyra-skills, drenyra-guardian-angel) for bug reports and feature requests. Issues are triaged by maintainers.
- **Discussions**: open a discussion or an issue for questions and general inquiries — public answers help everyone.

## Product Support

| Product | Channel |
| --- | --- |
| Drenyra ecosystem (all six repositories) | [Open an issue on the relevant repository](https://github.com/orgs/arkelythex/repositories) |
| Security | [SECURITY.md](SECURITY.md) — private vulnerability reporting |

## Response Times

| Severity | Response time |
| --- | --- |
| Critical (security, data loss) | Within 24h |
| High (blocking bug) | Within 48h |
| Normal | Within 5 business days |
| Low | Within 10 business days |

## Non-goals

- No private chat for bug reports — issues keep the audit trail.
- This organization does not provide tax/legal advice through support channels.
